# University App — 10 жаңа экран

## Қосу жолы
1. Жобаңыздағы `App.tsx` файлын осы архивтегі `App.tsx` нұсқасымен ауыстырыңыз.
2. Архивтегі `src/screens/` ішіндегі жаңа файлдарды жобаңыздың `src/screens/` папкасына көшіріңіз.
3. Бұрыннан бар экран файлдарын өшірмеңіз.
4. `npx expo start -c` командасымен қайта іске қосыңыз.

## Ескерту
Бұл қосымша экрандар үлгі деректермен жасалған UI. Нақты стипендия, төлем, күнтізбе және басқа деректерді backend/API-ға бөлек байланыстыру керек.
`More` (Қосымша) деген алтыншы табтан барлық 10 экран ашылады.
